# Human Operating System — beta

Авторский веб-тест из 48 жизненных ситуаций. После прохождения пользователь получает персональный профиль по 12 шкалам, проценты, сильные стороны и возможные слепые зоны.

**Рабочая версия:** https://human-operating-system-beta.millie-mk5.chatgpt.site

## Возможности

- один вопрос и четыре варианта ответа на экране;
- прогресс-бар и навигация назад/вперёд;
- сохранение прогресса на устройстве;
- итоговый профиль по 12 авторским шкалам;
- Top 5, сильные стороны и слепые зоны;
- копирование результата и отправка ссылки;
- адаптивный интерфейс для телефона и компьютера.

Модель, формулировки и подсчёт разработаны самостоятельно. Проект не использует вопросы, названия тем или алгоритмы Gallup/CliftonStrengths и не является клинически либо психометрически валидированным тестом.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Затем откройте http://localhost:3000.

## Проверка

```bash
npm run build
npm test
```

Основной интерфейс, вопросы и расчёт профиля находятся в `app/page.tsx`, стили — в `app/globals.css`.
